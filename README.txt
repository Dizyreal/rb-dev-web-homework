Портфолио: Дмитрий, девелопер игр в Roblox

Страницы:
- index.html: главная. Шапка с навигацией, вступление, разделы "О себе", "Работы" (4 карточки), "Услуги" (3 услуги), "Контакты" (почта и учебная форма), подвал.
- project.html: подробная страница проекта Tower Siege Simulator. Разделы "Задача", "Решение", "Результат", три изображения, ссылка "Вернуться к работам".
- css/style.css: единый файл стилей для обеих страниц

Изображения и источники:
- images/photo.jpg: личная фотография
- images/tsgreen.jpg, tshalloween.jpg, tsunits.jpg: рендеры из игры Tower Siege Simulator, предоставлены мной
- images/matchmaking.svg, playerstab.svg, invites.svg: упрощённые схемы систем. Сгенерированы ИИ для данного проекта
Информация об игре (и в целом ссылка на саму игру) взята со страницы https://www.roblox.com/games/11510916672/Tower-Siege-Simulator

Оформление:
Тёмная тема с красным акцентом, как у студий, делающих игры на Roblox. Три основных цвета: тёмный фон, светлый текст, красный для кнопок и заголовков. Шрифты: Arial Black для заголовков и Arial для текста. Макет одноколоночный: контейнер с max-width 900px, изображения с max-width: 100% и height: auto. Макет подстраивается под ширину экрана без медиазапросов и без JavaScript.

Примечания:
- Адрес hello@example.com демонстрационный.
- Форма учебная: сообщения не отправляются, браузер проверяет обязательные поля и формат email.
- Некоторый текст об игре или описание чего-либо могли быть сгенерированы ИИ для ускорения работы.
